# Study Hub

给大学生的 Canvas 学习助手：所有课的截止日期一屏看完、公告里的考试时间自动识别、成绩还差几分直接算、连上你自己的 AI 按课件出题和做闪卡。

A Canvas companion for students: every deadline on one screen, exam dates found in announcements, a grade calculator, and AI review with your own AI.

**官网 / Website:** https://17373624812qq-code.github.io/Study-Hub-releases/
